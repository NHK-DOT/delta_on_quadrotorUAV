# CAD Sources

`desktop_cad_import_20260714/` is the frozen CAD import used while developing
the 78arm UAV integration. It contains two distinct source groups:

- 78arm-specific Delta-arm parts and assemblies at the directory root.
- `【RM2024-空中机器人结构开源】-深圳大学-RobotPilots战队/`, an external
  RobotPilots RM2024 reference package.

The RobotPilots material remains third-party reference material. Its original
notice permits technical exchange and prohibits commercial use; do not present
it as a 78arm original design or redistribute it under this repository's GPL
license. The original local source package is retained on the Desktop under the
same name.

Large CAD binaries are managed through Git LFS. Before cloning or pushing this
directory, install and enable Git LFS.
