# UAV Integration Documentation

## English

This directory contains the 78arm-maintained integration documentation for the imported UAV project. `UAV_Delta_Capture_Integration_Report.docx` is generated from the local Wangdi report template while preserving its page layout and styles; its technical content is replaced with the NX, STM32MP257, UWB, ROS 2, vision, and Delta-arm architecture.

The report records source attribution, the strict NX/MP257 responsibility boundary, the observation-only UDP contract, Python 3.8 recovery on NX, and validation limits. It is not a flight authorization document.

## 中文

本目录保存由 78arm 维护的无人机集成文档。`UAV_Delta_Capture_Integration_Report.docx` 以本机“王迪论文报告”模板生成，保留原有页面布局与样式，只将技术内容替换为 NX、STM32MP257、UWB、ROS 2、视觉和 Delta 机械臂架构。

报告记录上游出处、严格的 NX/MP257 职责边界、只观测 UDP 协议、NX 的 Python 3.8 恢复和验证限制。它不是飞行授权文件。
