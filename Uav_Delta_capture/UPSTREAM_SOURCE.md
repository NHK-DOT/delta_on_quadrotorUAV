# Upstream Source / 上游来源

## English

This directory is an imported integration copy of the UAV ROS 2 project. It originates from `https://github.com/Nocoding0/Uav_Delta_capture.git` at commit `1c27e88051174780e2267d8d063ff80affeebd91` (`after the first competition`, fetched July 13, 2026).

It is intentionally maintained inside the 78arm repository so the NX vision-and-arm integration can evolve without pushing changes to the upstream repository. Do not add the upstream `.git` directory here. Upstream flight-control, UWB, and STM32MP257 code remains attributable to the source project.
