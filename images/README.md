# Project Images

This directory contains small, repository-ready images used by the project
README and documentation. Images are grouped by what they document rather
than by capture date.

| Directory | Contents |
| --- | --- |
| `airframe/` | UAV appearance, frame, propeller, and assembly progress photos. |
| `electronics/` | Power distribution, flight-control, compute, UWB, and drive-board photos. |
| `arm/` | Delta-arm mechanism, end-effector, camera mounts, and mechanical-detail photos. |
| `debug/` | Bench and field debugging photos, simulation views, and perception results. |

Keep full-resolution camera dumps, raw videos, and repeated intermediate
captures outside this directory. Add only the selected images required to
explain a hardware revision, integration state, or verification result.
